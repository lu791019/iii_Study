## 一句話用途

讓承辦人在網頁填表（可附會議錄音），系統套用主管機關的官方公文範本，即時預覽並產出 Word／PDF，再自動歸檔到雲端；錄音可由 AI 先擬草稿回填表單。

## 技術棧

| 層 | 技術 |
| --- | --- |
| 後端 | FastAPI、Pydantic、uv、pytest、ruff |
| 套版 | docxtpl（範本由 builder 程式產生）、LibreOffice headless 轉 PDF |
| 前端 | Vite＋React＋TypeScript，JSON Schema 動態渲染表單 |
| AI | Gemini（Vertex AI，服務帳號身分、免管理金鑰），供應商抽象 |
| 部署 | Cloud Run 單容器（node build 前端 → Python slim＋uv），雲端物件儲存歸檔 |

## 架構重點

```
選文件類型 → 讀 JSON Schema → 動態表單 → 法規檢核（警告不阻擋）→ 伺服器套版預覽 → 產出 Word／PDF → 歸檔 {單位}/{年度}/{檔名}
                     ↑
     （選用）錄音 → Gemini 單次呼叫：逐字稿＋依 schema 擷取欄位 → 套用草稿 → 人工逐欄確認
```

- `schemas/` 是單一事實來源：每種文件一個 Pydantic model（含 `compliance_warnings()`），`registry.py` 註冊。
- 新增一種文件只要 4 步（schema、註冊、範本 builder、context builder），**前端零修改**。
- 預覽與產出走同一條套版鏈路，「預覽 = 產出檔」永遠一致；未填欄位顯示「○○○」佔位，填一格亮一格。
- 資料層存西元，render 層才轉民國年與國字數字。
- 測試分 schema／docgen／API 三層，task.md 每批功能附測試數與 e2e 結果。

## 可借用的知識精華

1. **純手填是主幹，AI 是加值**：後端沒設 AI 時前端整塊隱藏，主流程完全不受影響。
2. **防幻覺三層**：prompt 明令「只填聽得到的、不得虛構」並回報待確認事項 → 後端丟掉 schema 外的鍵 → 前端只覆蓋有值欄位；最後人工確認。
3. **Schema 驅動 UI**：後端定欄位、前端照 schema 畫表單，新增類型不碰前端。
4. **範本用程式產生**：可重現、可版控；原始官方檔另存對照。
5. **法規檢核只警告不阻擋**：讓使用者自己判斷，避免工具卡住真實流程。
6. **失敗不靜默**：歸檔失敗照樣給下載，但回傳錯誤 header，前端顯示紅色警示「請保留本機檔案」。
7. **成本護欄**：每日 AI 呼叫上限、逾量回 429 並引導改手填；雲端設月預算警示；閒置縮到 0；映像清理政策（每次 `deploy --source` 都會累積映像，是最容易忽略的花費）。
8. **平台雷區要寫下來**：服務帳號沒有個人雲端硬碟配額、模型代號會下架（放環境變數覆寫）、`.m4a` MIME 類型要正規化、PDF 中文要裝字型並設對映、部署前確認 CLI 作用中的設定檔。
9. **外部資源做本地備援**：官方範本全量下載進 repo，防死鏈；同步腳本可重跑。
10. **給設計 AI 的需求書**：使用者與焦慮、要設計的畫面、硬約束（紅色只給逾期）、已定案行為、現況問題、參考範例各附「看什麼」；提示詞一次一張畫面，回饋指著具體元素講。

## 適合的教學案例／學員專題

- **教學案例**：真實接案 MVP 的完整生命週期（需求 → 骨架 → AI 加值 → 上線 → 現場回饋）；LLM 結構化擷取與防幻覺；雲端成本控管。
