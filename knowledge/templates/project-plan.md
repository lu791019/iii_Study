# 專題計畫書範本

依「第一階段專案計畫」格式，加上本 repo 的慣例（亮點實驗、驗證規則、風險表）。完整範例見 [docs-index.md](../docs-index.md) 中的馬匹健康結果預測計畫書。

## 章節

| # | 章節 | 必含內容 |
| --- | --- | --- |
| — | 摘要 | 一段話：資料、要預測或分析什麼、亮點、總時程 |
| 1 | 題目主題 | 題目名稱、主題說明（50–100 字）、資料來源（平台、資料集、連結、時間範圍與規模）、應用方向 |
| 2 | 內容方向 | 2.1 Input：檔案與欄位表（欄位、中文說明、類型、處理方式）；2.2 Output：預計產出、最後要畫的圖 |
| 3 | 專題亮點 | 可比較的實驗或決策，附對照圖與比較表（優點、缺點、要驗證的假設） |
| 4 | 實驗流程 | 六步驟：資料收集 → 清理與 EDA → 特徵工程 → 訓練 → 驗證 → 判讀；每步寫目標、做法、產出 |
| 5 | 驗證方式與指標 | 公平比較規則、指標表、判讀方式 |
| 6 | 主要技術 | 「套件＋用途」表 |
| 7 | 時程規劃 | 週次、階段、工作內容、檢核點；含緩衝週 |
| 8 | 預期成果 | 預期表現（標明估計值）、亮點、最後的圖、交付項目 |
| 9 | 風險與對策 | 風險、影響、對策；含進度落後備案 |
| — | 參考資料 | 競賽或資料集連結、文件連結 |

## 版本

- **含程式版**：第 4 節每步附 Python 範例，給學員實作參考。
- **無程式版**：只寫做法與產出，給審核者或非技術讀者。
